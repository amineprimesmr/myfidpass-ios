# Icônes à fournir pour les cartes fidélité (tous secteurs)

Tu mets tes propres images (PNG) dans **`fidelity/backend/assets/icons/`** (dossier dédié ; le backend le prend en charge en priorité).  
Chaque fichier doit s’appeler **`icon_XXXX.png`** (XXXX = code Unicode en minuscules, sans tiret pour les multi-codepoints on utilise un tiret).  
Format recommandé : **128×128 px ou 256×256 px**, fond transparent, style cohérent entre toutes les icônes.  
Pour un emoji à plusieurs codepoints, le nom utilise des **underscores** (ex. `icon_2764_fe0f.png`). Le backend ignore le sélecteur de variation (fe0f) donc `icon_2764.png` suffit pour ❤️.

## Où mettre les fichiers

- **Backend (pass Apple Wallet / génération des passes)** :  
  **`fidelity/backend/assets/icons/`** (dossier géré en priorité par le backend).  
  Fichiers nommés **`icon_XXXX.png`** (XXXX = code de la table ci‑dessus).

- **App iOS** : les mêmes visuels peuvent être utilisés en local si tu les ajoutes au bundle (Asset Catalog) pour l’aperçu « Ma Carte » ; le pass lui est généré côté backend avec les PNG du dossier ci‑dessus.

---

## Style conseillé

- **Taille** : 128×128 ou 256×256 px.  
- **Fond** : transparent.  
- **Style** : cohérent (même trait, même niveau de détail, même palette ou monochrome).  
- **Forme** : carré ou cercle, le backend redimensionne et peut rogner si besoin.

Tu peux faire une seule série d’icônes (ex. 3D type “clay”, ou flat) et les exporter en PNG pour chaque code ci‑dessus.
